How the browser-native workflow works, what files are supported, and how to troubleshoot a difficult cutout.

Getting started

Open the background remover, choose a portrait, and run the tool. The first edit downloads the model files; later edits use the browser cache. If the mask looks reversed on an unusual photo, tick the Invert option and run it again.

Supported files

The picker accepts JPG, PNG, and WebP files. HEIC files should be converted to PNG or JPEG first because browser support varies by operating system.

Privacy and security

Images are read with the File API and processed through Canvas. The Worker serves static files only and never reads a request body. Browser ads may set cookies on content pages, but they do not receive image pixels.

Offline use

After the page shell and model files are cached, the core editing flow can work without a network connection. Clearing site storage removes the cache.

Troubleshooting

  • Soft edges: use a photo with a plain background and even lighting.
  • Reversed result: tick the Invert option and run the tool again.
  • Page feels slow: close other memory-heavy tabs and use a smaller source image.
