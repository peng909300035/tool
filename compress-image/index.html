FAQ

Compress questions

Does compressing an image reduce quality?

JPG and WebP are lossy formats, so lowering quality removes some detail. Start around 80 percent and preview the result. PNG is lossless and will usually get larger instead of smaller.

Which output format should I choose?

Use JPG for ordinary photos, WebP for smaller web images, and PNG only when you need lossless pixels or transparency.

Is my image uploaded anywhere?

No. Compression runs through the Canvas API in your browser. The file is read into memory, processed, and exported back to your device.

Why did my PNG get bigger?

PNG stores pixels losslessly, so re-encoding a photo as PNG often increases file size. Choose JPG or WebP for photographs.
