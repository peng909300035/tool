FAQ

Resize questions

How do the width and height fields work?

Fill in one dimension and the other is calculated from the original aspect ratio. Fill in both to set an exact size.

Which preset should I use?

Square works for Instagram posts, 1080 × 1350 for portrait posts, 1200 × 630 for link previews, and 500 × 500 for avatars.

Does resizing improve image quality?

No. Resizing changes pixel dimensions. Downscaling can reduce file size, but it cannot add detail that was not in the original.

Are my images uploaded?

No. Resizing uses Canvas in your browser, so the original file never leaves your device.
