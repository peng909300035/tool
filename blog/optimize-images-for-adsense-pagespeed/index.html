Optimize images for PageSpeed on a content site

Practical image choices that improve Core Web Vitals without hurting readability or ad revenue.

Advertisement

PageSpeed affects user experience and search visibility. For content sites, images are usually the easiest place to gain speed.

Set dimensions

Always declare image width and height so the browser can reserve space. This prevents layout shifts while images load.

Choose formats carefully

Use WebP or AVIF for photographs when your delivery pipeline supports them. Keep PNG for transparency or screenshots where sharp edges matter.

Lazy-load below the fold

Images far down the page should load only when needed. Hero images should not be lazy-loaded, because they affect the largest contentful paint.

Leave room for ads

Ads that shift article text create a poor reading experience. Reserve stable containers before the ad script loads, and avoid placing ads next to interactive controls.

Measure real pages

Run PageSpeed on an actual article URL, not just the homepage. Article pages often have more images and ad slots than the landing page.
