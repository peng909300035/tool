How service workers make image tools available offline

A plain-language look at caching app shells, model files, and the limits of offline browser tools.

Advertisement

A service worker is a script that runs in the background of a web page. It can intercept network requests and serve cached files when you are offline.

App shell caching

The HTML, CSS, and JavaScript that make up the interface can be cached during installation. After that, the page can open even without a connection.

Model caching

AI models are static files too. Caching them is what makes local inference practical after the first visit. The model is downloaded once, not on every edit.

Limits

Offline support does not remove browser storage limits, and clearing site data removes the cache. Ad scripts and external resources may also fail while offline.

Do not cache user images

A privacy-first tool should cache only public static assets. Photos selected by the user belong in memory, not in the Cache API or IndexedDB.
