FAQ

Convert questions

Which formats can I convert between?

The converter handles PNG, JPG, and WebP. All three are supported natively by modern browsers, so conversion happens locally.

Will conversion keep transparency?

PNG and WebP can store an alpha channel. JPG cannot, so transparent areas are flattened onto white when you convert to JPG.

Does conversion remove EXIF data?

Yes. The export is rebuilt from canvas pixels, so metadata from the original file is not carried into the new image.

Is there a file size limit?

There is no server upload limit because nothing is uploaded. Very large images are limited only by your device memory.
